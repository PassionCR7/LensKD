# 实验脚本

本目录存放 README 中数据性结论的复现脚本。原始输出（JSON）在 `results/`。

## exp1 · 投影残差与理论下界

```bash
python experiments/exp1_projection_lower_bound.py
```

### 它回答什么

README 声称"`lstsq` 投影残差 0.88621 恰等于维度决定的理论下界"。本脚本用
**三种互相独立的算法**算同一个量，检验它们是否收敛到同一数值：

| 算法 | 做法 | 理论依据 |
|---|---|---|
| `lower_bound_qr` | `residual = ‖(I − QQᵀ)W_t‖ / ‖W_t‖` | `W_s` 的 QR 分解直接给出正交投影 |
| `lower_bound_svd` | 用 SVD 求伪逆后投影 | 与 `lstsq` 走不同的数值路径 |
| `lower_bound_spectrum` | `√(1 − Σ_{i≤d_s}σ_i² / Σσ_i²)` | 奇异值谱的闭式解，**不依赖具体 `W_s`** |

### 三个问题

- **Q1** 实际残差是否等于 README 的 0.88621？
- **Q2** 三种算法是否互相一致？不一致的话差在哪、为什么？
- **Q3** 残差随公共 token 数 `S` 如何变化（扫 10%/25%/50%/75%/100%）？

### 依赖

需要真实的教师和学生 `lm_head` 权重：

- 教师：safetensors 流式读取（`safe_open`），不整模型加载
- 学生：`.pth` 权重

路径在脚本顶部的 `TEACHER_DIR` / `STUDENT_CKPT` 常量里改。跑不起来时先看
这两项，以及 `config.py` 里的词表大小是否与实际权重匹配。

### 关键结论

1. Q1 复现成功：0.886174 vs 声称 0.88621，差 3.6e-05。
2. Q2 中 QR 与 SVD 与 `lstsq` **完全相等（gap = 0.0）**，证明伪逆是线性最优解；
   但谱闭式给 0.5118，差 0.374。**0.886 不是绝对下界**，而是固定 `W_s` 时的
   最优值——真正的瓶颈在学生嵌入几何，不在投影器。
3. Q3 残差随 `S` 单调上升且非线性（10% → 0.326，25% → 0.746，之后饱和），
   说明不要盲目追求高词表覆盖率。
4. 消融：伪逆 (0.886) 明显优于 identity_like (1.297) 和 random (1.249)。
